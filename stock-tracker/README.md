# 📈 StockLens — 株価チェック & 情報収集・整理アプリ

日経225銘柄・ETF・米国主要株(S&P500 / NASDAQ)の株価推移チェック、関連情報の収集・整理、
Q&A、簡易財務分析ができる **純HTML/JSアプリ**(ビルド不要・サーバー不要)。

## 使い方

`index.html` をブラウザで開くだけで動作します(`file://` 直開きOK)。

```bash
# ローカルサーバーで開く場合
cd stock-tracker
python3 -m http.server 8080
# → http://localhost:8080
```

## 機能

| 機能 | 説明 |
|------|------|
| 📊 株価チャート | SVG製インタラクティブチャート。期間切替(1M/3M/6M/1Y)、移動平均線(MA25/75)、出来高、クロスヘア+ツールチップ、イベントマーカー(クリックで詳細) |
| 📰 ニュース・イベント | LLMクローラー(Claude)がWebから収集・要約・日付紐付けした銘柄関連情報の時系列表示 |
| 🌐 市場全体の動き | 日銀・FOMC・急落急騰など市場全体の重要イベントまとめ(日本/米国フィルタ付き) |
| 💬 マーケットQ&A | 「2025年12月3日ごろに株価が大きく変動した理由は?」のような日本語質問に、収集済みデータから回答 |
| 📊 財務分析 | PER/PBR/ROE/配当利回り/自己資本比率の指標タイル+5軸レーダーチャート+自動生成の見解・アドバイス |
| 🧮 ファクター分析 | バリュー/クオリティ/モメンタム/低ボラティリティ/配当/サイズの6ファクターを個別株横断で偏差値化。ファクターマップ(散布図・軸選択可)、スタイル自動判定(バリュー株/グロース株等)、ファクター別ランキング |
| 🌙 テーマ | ライト/ダーク切替(OS設定に追従、手動切替可) |

## データについて

- `research/*.json` … LLMクローラー(Claude + Web検索)が収集した**実データ**
  (株価アンカー点・ニュースイベント・財務指標・市場イベント)
- `data/stock-data.js` … アプリが読む生成済みデータ。
  日次の株価系列は、実データのアンカー点を通るように補間合成した**参考値**です。
  正確なのはアンカー点・イベント・財務指標で、日々の細かい値動きは実際と異なります。

### データの更新方法

1. Claude に「株価データを再収集して」と依頼(または `research/*.json` を手動更新)
2. 生成スクリプトを実行:

```bash
node scripts/generate-data.js
```

### J-Quants API 連携(日本株の実データ化)

[J-Quants](https://jpx-jquants.com/)(JPX公式API、無料のFreeプランあり)のアカウントがあれば、
日本株6銘柄+国内ETF2本の日足を**取引所公式の調整済み実データ**に置き換えられます。
決算データからROE・自己資本比率・PER/PBR・配当利回りも実数で更新されます。

```bash
export JQUANTS_MAIL_ADDRESS="you@example.com"
export JQUANTS_PASSWORD="********"
# (または export JQUANTS_REFRESH_TOKEN="...")

node scripts/fetch-jquants.js    # → research/jquants_data.json に保存
node scripts/generate-data.js    # → data/stock-data.js に反映
```

- 実データ化された銘柄には画面上に「📡 J-Quants実データ」バッジが付きます
  (それ以外は「📝 参考値」= アンカー補間の合成系列)。
- Freeプランの日足は約12週間遅延・過去2年分です(Light以上は前営業日まで)。
- 認証情報は環境変数でのみ渡し、取得データ(`research/jquants_data.json`)は
  J-Quantsの利用規約(再配布制限)に基づき `.gitignore` 済みです。

#### プラン別の追加機能(自動判定)

契約プランを自動判定し、利用可能なAPIだけを取得します(未契約分はスキップ)。
上位プランで取れたデータは、アプリに以下のUIが自動的に追加されます:

| プラン | データ | 画面反映 |
|---|---|---|
| Free | 日足(12週遅延)+決算指標 | 実データチャート+財務指標の実数化 |
| Light以上 | TOPIX指数の日足 | チャートに「TOPIX比較」トグル(表示起点で正規化した破線を重ね描き) |
| Standard以上 | 銘柄別の信用買残・売残(週次) | 財務分析タブに「信用残トレンド」カード(信用倍率も表示) |
| Premium | 配当履歴・詳細財務諸表 | 財務分析タブに「配当推移」カード+指標タイルに営業CF |

## 構成

```
stock-tracker/
├── index.html            # アプリ本体(SPA)
├── css/style.css         # モダンUI(ライト/ダーク対応)
├── js/
│   ├── app.js            # メイン制御(サイドバー・タブ・Q&Aパネル等)
│   ├── chart.js          # SVGチャート描画(株価・出来高・レーダー)
│   ├── qa.js             # Q&Aエンジン(日付・銘柄・意図の解析と回答生成)
│   ├── analysis.js       # 財務スコアリングとアドバイス文生成
│   └── factor.js         # ファクター分析(偏差値化・スタイル判定・ランキング)
├── data/stock-data.js    # 生成済みデータ(自動生成・編集不可)
├── research/             # LLMクローラー収集の生データ(JSON)
└── scripts/generate-data.js  # データ生成スクリプト
```
