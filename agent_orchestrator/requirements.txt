# No third-party dependencies are required.
#
# The orchestration core, the web UI, AND the LLM API adapters all run on the
# Python standard library only (the API adapters call the providers' REST
# endpoints directly via urllib — no SDKs, no compiled wheels). This keeps the
# tool friendly to locked-down / audited environments: nothing to pip-install,
# no native binaries, no .exe.
#
# To use the API backends you only need the relevant API key set in the
# environment (see .env.example):
#   - Claude (API)   -> ANTHROPIC_API_KEY
#   - GPT (API)      -> OPENAI_API_KEY
#   - Local LLM      -> a running OpenAI-compatible server (e.g. Ollama)
#
# OPTIONAL — only for the browser_get agent tool's JavaScript rendering. Without
# either, browser_get still works but falls back to a plain HTTP fetch (no JS).
# Install ONE of:
#   pip install selenium         # + a Chrome/Chromium and matching chromedriver
#   pip install playwright && playwright install chromium
# The http_get tool needs nothing extra (stdlib), and honors the proxy + the
# configured User-Agent.
