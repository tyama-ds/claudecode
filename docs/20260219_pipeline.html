パイプライン & パラメータ リファレンスマップ — 2026-02-19

1. パイプライン全体フロー

Phase 1

Config構築

create_config() → 8つのサブ設定を持つ Config オブジェクト生成
Phase 2

コンポーネント初期化

DeepResearchTool(config)
  • LLMClient（OpenAI / Anthropic / Local）
  • SearchClient（DuckDuckGo / Selenium）
  • ContentFilter（strict / moderate / minimal / none）
  • DeepThinkProcessor（deep_think=True 時のみ）
Phase 3

リサーチ実行

Researcher.conduct_research(query, requirements)
  • クエリ生成・リサーチ計画策定
  • 反復検索ループ（min〜max iterations）
  • 条件付き 多言語検索（multilingual=True）
  • 条件付き 拡張クロール（extended_mode=True）→ SiteCrawler
  • ContentExtractor：チャンク分割（6000字+500字overlap）→ LLM抽出 → Jaccard重複排除
  • 条件付き 拡張合成（use_enhanced_synthesis=True）：ポイント生成→統合→最終合成
  • EvidenceLockerにエビデンス保存
Phase 4

コンテンツ拡張

_expand_if_needed() — 目標文字数に不足時、追加調査を実行
Phase 5

DeepThink処理 deep_think=True

_apply_deep_think()
  • Tree of Thought推論（reasoning_iterations回）
  • 一貫性チェック（consistency_threshold）
  • ソース忠実度検証（fidelity_threshold）
Phase 6

エビデンスエクスポート

evidence_locker.export_to_json() / export_to_csv()
Phase 7

検証 enable_verification=True

Verifier.verify_content(content, evidence_locker, strictness)
  • クレーム抽出・分類（statistics / dates / quotes / causal / comparative / absolute / predictions / historical）
  • エビデンス照合 → 信頼度スコアリング（HIGH / MEDIUM / LOW / UNSUPPORTED / CONTRADICTED）
  • HTML検証レポート生成（日本語対応済み）
Phase 8

レポート生成

_create_report_generator() → V1 / V2 / V3 から選択
  • V1：基本Markdown生成 → 各形式に変換
  • V2：用語集管理・章間一貫性・2段階生成・原文+要約参照・散文スタイル
  • V3：V2全機能 + DOCX直接生成・インライン図表挿入
Phase 9

オプション後処理

  • fermi_estimation=True フェルミ推定 → 分解ツリー・モンテカルロ・感度分析
  • auto_figures=True 自動図表生成 → FigureTableGenerator

結果Dict返却

report_path, evidence_json/csv, verification_html, deep_think_results, fermi_results, token_usage

5. パラメータフロー図

5.1 target_pages の流れ

run_research(target_pages=N)
  → Config.report.target_pages = N
  → Researcher.__init__(target_pages=N)
    → self._target_pages = N
    → target_chars = N × 1600
    → target_per_section = target_chars ÷ セクション数
    → ContentExtractor.target_chars_per_section = target_per_section
      → _calc_target_per_point(num_points)
        → raw = section_target ÷ num_points
        → clamp(500, raw, 3000)

5.2 extended_mode の流れ

run_research(extended_mode=True)
  → Researcher(extended_mode=True, crawl_max_pages, crawl_max_depth, crawl_max_sites)
    → 検索結果取得後
    → SiteCrawler(max_pages, max_depth) で各サイトを深層クロール
    → crawl_relevance_threshold で関連ページをフィルタ
    → ContentExtractor で各ページからコンテンツ抽出

5.3 deep_think の流れ

run_research(deep_think=True, deep_think_level=0.7)
  → DeepThinkProcessor(config)
    → リサーチ完了後、全セクションに対して実行
    → Tree of Thought推論 × reasoning_iterations 回
    → consistency check（threshold超過時に mode に応じて対応）
      ├─ warn: 警告のみ
      ├─ revise: 自動修正
      └─ strict: 修正+再検証
    → fidelity check（ソース忠実度検証）
